# AI for FinTech and Financial Engineering — Spring 2027

This repository contains materials for the master's-level course **AI for FinTech and Financial Engineering**.

The course is application-oriented and focuses on how modern artificial intelligence and machine learning methods can be used to solve practical problems in quantitative investment, financial engineering, and FinTech.

Unlike the PhD-level **Machine Learning for Finance** course, which emphasizes academic research and frontier literature, this course emphasizes **implementation, end-to-end financial workflows, and practical decision-making**.

---

## 🧭 Course Philosophy

The course is organized around four connected stages:

1. **Learn the AI toolkit**
2. **Make investment decisions**
3. **Solve financial engineering problems**
4. **Build modern FinTech systems**

The central learning journey is:

> **Learn AI → Invest → Engineer Risk → Build FinTech Systems**

Rather than studying machine-learning algorithms in isolation, students learn a compact set of methods and apply them repeatedly to real financial problems.

## 🔗 Learning Workflows

### AI for Investment

**Predict → Allocate → Trade**

- predict expected returns and financial signals,
- translate predictions into portfolios,
- understand market microstructure and execution.

### AI for Financial Engineering

**Price → Calibrate → Hedge → Simulate**

- use AI as a surrogate for computationally expensive derivative pricing,
- calibrate financial models to market data,
- learn dynamic hedging policies,
- generate financial scenarios and synthetic market data.

### AI for FinTech

**Credit/Fraud → LLM/RAG → AI Agents**

- build predictive systems for credit and fraud,
- process unstructured financial information,
- integrate LLMs, retrieval, financial databases, and tools into AI workflows.

## 🚀 Final Project

Students complete an applied final project and present their work in **Week 13**.

Projects should follow the structure:

> **Problem → Data → AI Solution → Evaluation → Financial Value**

Possible directions include:

- quantitative investment and portfolio construction,
- trading and market microstructure,
- derivative pricing and model calibration,
- deep hedging and reinforcement learning,
- synthetic financial data and stress scenarios,
- credit scoring and fraud detection,
- financial LLMs, RAG, and AI agents.

### Expected Deliverables

- code or reproducible analysis,
- concise report or technical documentation,
- final in-class presentation.

A formal one-page project proposal is not required.

## 🧠 Recommended Background

Students should ideally have:

- basic probability and statistics,
- introductory finance or financial engineering,
- basic machine learning,
- Python programming.

The course emphasizes practical implementation rather than advanced mathematical derivations.

## 🔄 Relationship to Machine Learning for Finance

This course complements the PhD-level **Machine Learning for Finance** course.

| Machine Learning for Finance | AI for FinTech and Financial Engineering |
|---|---|
| PhD level | Master's level |
| Research-oriented | Application-oriented |
| Academic literature | Practical financial workflows |
| Frontier research questions | Implementation and decision-making |
| Research-style final project | Applied final project |
| Strong asset-pricing emphasis | Financial Engineering + FinTech emphasis |

Where appropriate, selected technical foundations are adapted from the PhD course at a more applied level.
